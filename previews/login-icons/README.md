# Login icons

Lucide is the owner-selected default for general UI icons (web and mobile). Demo SVGs are unmodified artwork from `lucide-static@1.77.0`, renamed by role. Custom Smashi artwork and provider marks are separate from Lucide.

Provider marks are for design preview only: Apple glyph from `simple-icons@16.38.0` with Off White fill; Google multicolor G is a local preview SVG. Do not treat either preview file as official provider-supplied artwork or production approval. Production apps must use provider-approved assets and follow applicable button rules. Google is the currently supported method per the owner. Apple is shown only for design review and must be hidden in consumers until Apple sign-in is implemented.

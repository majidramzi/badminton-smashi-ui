# Smashi UI v4 — developer handoff for Majid's AI

> Shared backdrop direction: [static backgrounds and adjustable halos](design-system/patterns/static-background.md).
> For current logo selection and slogan rules, use the [Smashi logo contract](docs/BRAND_LOGO.md). It supersedes older logo examples below.

This ZIP **extends v3** and retains the dashboard, existing icon pairs, login/wizard components, splash assets, and brand palette.

## Start here
1. `docs/V4_DELIVERY_STATUS.md` — exactly what's included and still missing.
2. `docs/CURSOR_PROMPT.md` — implementation prompt for Cursor/Claude.
3. `assets/brand/APPROVED_SMASHI_LOGO_SOURCE.png` and `APPROVED_S_SYMBOL_SOURCE.png` — unchanged user-approved raster sources.
4. `assets/brand/*transparent.png` — cutout PNG convenience exports.
5. `assets/app-icon/` — icon exports and Android adaptive icon resources.

7. `src/components/` — login and training wizard starters.
8. `assets/splash/` and `docs/SPLASH_ANIMATION.md` — splash/diagonal pattern assets and motion spec.

**Important:** Exact editable SVG path-based logo requires an original vector master. Existing SVG wrappers are raster-embedded; they are not true vector artwork. This is a developer handoff, not a complete app.
